# Exercícios do módulo 4

Em cada exercício, os arquivos fonte (`.java`) ficam em `src` e os arquivos compilados (`.class`) ficam em `bin`.

Exemplo para compilar e executar:

```bash
cd "Atividade 4/Exercicio3/src"
javac -d ../bin CodigoMorse.java
java -cp ../bin CodigoMorse
```

No exercício 1, o pior caso ocorre quando os cinco valores são distintos, por exemplo: `10, 20, 30, 40, 50`.

No exercício 5, o bubble sort é `O(n²)` porque, no pior caso, realiza `n(n - 1)/2` comparações.
