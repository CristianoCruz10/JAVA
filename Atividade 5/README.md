# Exercícios do módulo 5

Cada exercício é independente: os arquivos fonte (`.java`) ficam em `src` e os binários (`.class`) ficam em `bin`.

## Exercício 5 — hierarquia

`Quadrilátero → Trapézio → Paralelogramo → Retângulo → Quadrado`

`Quadrilátero` guarda os quatro pontos como atributos privados. As subclasses calculam a área pelo método do polígono (fórmula do cadarço), adequado para os pontos informados em ordem ao redor da figura.
